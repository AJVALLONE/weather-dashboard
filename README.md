# Weather Dashboard

A live weather application built with vanilla JavaScript and the OpenWeatherMap API.

## Features
- Search any city worldwide for real-time weather
- Current conditions: temperature, feels like, humidity, wind speed, visibility
- 5-day forecast with daily high/low temperatures
- Full error handling for invalid city names
- Responsive layout for mobile and desktop
- Demo mode — works without an API key for presentation purposes

## Tech Stack
HTML5 · CSS3 · JavaScript (ES6+) · REST API · Fetch API · Promise.all

## Live Demo
[View Live →](https://ajvallone.netlify.app/weather-dashboard.html)

## Setup
1. Clone or download this repo
2. Get a free API key at [openweathermap.org](https://openweathermap.org/api)
3. Open `index.html`, find `const API_KEY = 'YOUR_API_KEY_HERE'` and replace with your key
4. Open `index.html` in any browser — no build tools needed
